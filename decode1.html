ANATOMY OF ACTION: HTTP METHODS

Understanding GET, POST, PUT & DELETE

GET

  • Retrieve Data
  • Safe Method
  • Idempotent

POST

  • Create Resource
  • Unsafe
  • Non-Idempotent

PUT

  • Update Resource
  • Replace Data
  • Idempotent

DELETE

  • Delete Resource
  • Permanent Removal
  • Idempotent

Fractal scale data exchange. Lightweight. Machine-parsable. Human-readable.

What is JSON?

JSON (JavaScript Object Notation) is a lightweight data exchange format that is easy for humans to read and write and easy for machines to parse.

Features

  • Lightweight
  • Human Readable
  • Machine Parsable
  • Language Independent
  • Used in REST APIs
